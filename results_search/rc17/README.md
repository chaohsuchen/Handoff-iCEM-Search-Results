# RC17 (view over rc01)

The RC17 variant that is built in this project is RC01 with `delay_s` (the delay of the observation that reaches the controller). `members.json`: `delays` = labels per delay_s over all rc01 runs; `contrasts[]` = the same scene and policy at different delays whose label differs (the contrast RC17 asks for), each with the run folder of every delay. The md's planned RC17 (RC16 + a lag on the car's sensing and actuation) is **not** built.
