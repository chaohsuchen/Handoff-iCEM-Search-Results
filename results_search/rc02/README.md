# RC02 (view over rc01)

RC02 is the RC01 van scene at a gap too short to stop in. It has no scene of its own (`docs/scenes/20RCs.md`), so this folder only lists the rc01 run folders that are RC02 cases: `members.json` -> `scenes[]` = the scene parameters, and for each the evaluated policies with their run folders (`dir`) and labels. Every one of them FAILs (negative cases, `UNRESOLVED` does not occur). All format rules of the run folders are those of rc01.
