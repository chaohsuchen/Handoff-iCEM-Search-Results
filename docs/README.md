# docs/: which file to open

| you want to | open |
|---|---|
| use the data (first read) | `../results_search/DELIVERY_STATUS.md`, then `RUN_SCHEMA.md` |
| understand what Victor and Kent did, how many variations, what was found (plain language) | `report.md` |
| see how Fred's requests (R1 to R9, Q1 to Q7) were answered | `handoff/PIPELINE_HANDOFF_REPLY.md` (his questions: `handoff/PIPELINE_HANDOFF.md`) |
| know what each RC scene is (options, variations, hidden settings) | `scenes/20RCs.md`; grouping and reuse: `scenes/RC_GROUPS.md` |
| add a new RC or re-run a batch | `extending/NEW_RC_CHECKLIST.md` (and the "Reproducing runs" section of the top-level `README.md`) |
| read about the RC04 free-form policy pilot | `extending/FREE_SEARCH_PROPOSAL.md`, `../results_free/README.md` |
| see how Kent's engine works (kept as written) | `kent/ENGINE.md`, `kent/RESULTS_README.md` |

`RUN_SCHEMA.md` is the contract for a run folder (files, columns, units, signs, which files a model may read).
